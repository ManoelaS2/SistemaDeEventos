O SVG Logo.svg incorpora uma imagem PNG e contém comentários sobre sua estrutura.
Não é preciso modificar os dados base64 para estudar a lógica do sistema.

As capas e fotos enviadas nos formulários não são salvas nesta pasta: ficam na coleção
midias do IndexedDB. Eventos usam capaId e palestrantes usam fotoId para encontrá-las.
No HTML, alt descreve uma imagem informativa; alt vazio indica imagem decorativa.
