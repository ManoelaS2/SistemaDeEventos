# Sistema de Eventos (EAS)

Sistema acadêmico de administração de eventos, desenvolvido em equipe durante a graduação em Sistemas de Informação.

## 🗄️ Banco de Dados

Este repositório contém a **modelagem do banco de dados relacional** do sistema.

Inclui:
- Estrutura de tabelas e relacionamentos
- Consultas SQL
- Modelagem relacional

## 💻 Tecnologias

- SQL
- Banco de dados relacional

## 👥 Projeto em equipe

Desenvolvido como parte das disciplinas de **Banco de Dados** e **Engenharia de Software**.

## 📄 Documentação

Documentação técnica extensa elaborada durante o projeto (~70 páginas).

## 📌 Status
