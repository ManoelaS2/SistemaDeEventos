Atue como um Especialista em DBA MySQL. Sua tarefa é analisar e comparar os planos de execução de duas queries (Original vs. Otimizada).

Instruções:

Analise o EXPLAIN (tabela) e o EXPLAIN ANALYZE (árvore de execução) de ambas.

Identifique gargalos como: Full Table Scans, Filesort, Temporary Tables e Hash Joins ineficientes.

Gere uma tabela comparativa final.

SELECT DISTINCT 
    *, 
    (SELECT 
        CASE WHEN LOWER(permissoes_nome) LIKE '%criar_evento%' THEN 'SIM' ELSE 'NÃO' END 
     FROM permissoes 
     JOIN permissoesusuarios 
        ON permissoes_id = permissoesusuarios_permissoes_id 
     WHERE permissoesusuarios_usuario_id = usuario_id

FROM eventos 
JOIN usuario 
    ON usuario_id = eventos_criador_usuario_id 
LEFT JOIN permissoesusuarios 
    ON permissoesusuarios_usuario_id = usuario_id

    ON permissoes_id = permissoesusuarios_permissoes_id
