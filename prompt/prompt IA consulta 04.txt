Atue como um Especialista em DBA MySQL. Sua tarefa é analisar e comparar os planos de execução de duas queries (Original vs. Otimizada).

Instruções:

Analise o EXPLAIN (tabela) e o EXPLAIN ANALYZE (árvore de execução) de ambas.

Identifique gargalos como: Full Table Scans, Filesort, Temporary Tables e Hash Joins ineficientes.

Explique por que a versão otimizada performa melhor.

Gere uma tabela comparativa final.

Dados para Análise:

1. Consulta Original (Não Otimizada)
Query: 
SELECT 
    cidade_nome AS cidade, 
    COUNT(DISTINCT usuario_id) AS quantidade_usuarios 
FROM usuario 
INNER JOIN endereco 
    ON endereco_usuario_id = usuario_id 
INNER JOIN cep 
    ON endereco_cep_id = cep_id 
INNER JOIN cidade 
    ON cep_cidade_id = cidade_id 
WHERE cidade_nome IS NOT NULL 
  AND cidade_nome != '' 
GROUP BY cidade_id, cidade_nome 
ORDER BY quantidade_usuarios DESC;

2. Consulta Otimizada
Query:
SELECT 
    cidade_nome AS cidade, 
    COUNT(endereco_usuario_id) AS quantidade_usuarios 
FROM cidade 
INNER JOIN cep 
    ON cidade_id = cep_cidade_id
INNER JOIN endereco 
    ON cep_id = endereco_cep_id
WHERE cidade_nome > ''
GROUP BY cidade_id, cidade_nome
ORDER BY quantidade_usuarios DESC;
